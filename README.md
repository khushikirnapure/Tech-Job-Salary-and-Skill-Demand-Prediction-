# Tech Job Salary and Skill Demand Prediction

## 📌 Project Overview

The **Tech Job Salary and Skill Demand Prediction** project aims to analyze the technology job market and predict salaries based on job roles, experience, location, and required technical skills.

The project also identifies the most in-demand technical skills in the IT industry and explores the relationship between skills, experience, and salary.

Using statistical analysis and machine learning techniques, this project provides insights into current technology job-market trends.

## 🎯 Objectives

- Collect technology job-related data using web scraping and publicly available datasets.
- Analyze salary trends across different technology job roles.
- Identify the most demanded technical skills in the IT industry.
- Study the relationship between experience, skills, and salary.
- Apply probability distributions and the Central Limit Theorem.
- Perform statistical inference using confidence intervals and hypothesis testing.
- Develop a regression model to predict tech job salaries.

## 📊 Problem Statement

To predict the salary of technology professionals based on factors such as job role, years of experience, location, and required technical skills, while analyzing the demand for different technical skills in the job market.

**Problem Type:** Regression

**Target Variable:** Salary
